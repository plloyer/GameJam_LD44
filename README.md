# GameJam_LD44

Unity project started for Ludum Dare 44 (April 2019).

- **Engine:** Unity 2019.1.0f2
- **Platform:** Android, using Google ARCore (`Assets/GoogleARCore`)
- **Scene:** `Assets/Scenes/SampleScene.unity`

## Setup

1. Install Git LFS, then clone: `git lfs install && git clone https://github.com/plloyer/GameJam_LD44.git`
2. Open the folder in Unity 2019.1.
3. ARCore Cloud Services: the API key was removed from `ProjectSettings/ARCoreProjectSettings.json`. Put your own in there if you need it.
